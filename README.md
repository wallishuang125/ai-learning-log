# My AI Crash Course — 7-Week Syllabus

> A self-directed, phase-based AI learning plan for a professional brand designer.
> 2–3 hours/day, Mon–Fri. Built in public on 小红书 and GitHub.

---

## Overview

| Phase | Topic | Duration |
|-------|-------|----------|
| Phase 1 | Info System — stop consuming, start connecting | 1 week |
| Phase 2 | Vibe Coding — build things, no coding needed | 2 weeks |
| Phase 3 | Create — AI for brand design & video | 2 weeks |
| Phase 4 | Ship & Share — workflows, capstone, presence | 2 weeks |

**Total: 7 weeks**

---

## Phase 1 — Info System (Week 1)

> Build the infrastructure that turns scattered content into a working knowledge base.

### Week 1 — The full setup in 5 days

| Day | Learn | Do / Make |
|-----|-------|-----------|
| Mon | Why most people drown in AI content. The 3-layer filter: skim → save → synthesize. Audit your current follows: who teaches vs who just hypes. | Create one X list "AI signal" — educators with first-hand insight only, no reposts. Aim for 10–15. Subscribe to 2 newsletters (TLDR AI + The Rundown). |
| Tue | How to process videos and posts: watch at 1.5x, pause at insights, capture in your own words. The weekly 15-min synthesis ritual. | Rewatch one video from an educator you already follow — notes in your own words only. Run your first synthesis: 3 sentences: what I learned / what I'll try / what surprised me. |
| Wed | Building a personal AI knowledge base in Notion or Claude Projects. Goal: retrieval and connection, not just storage. Using Claude as a thinking partner to connect dots across content you've consumed. | Set up your learning log: date / tool or concept / your take / idea sparked. Add 5 entries. Paste 3 recent AI posts into Claude and ask: "What's the common thread for a brand designer?" |
| Thu | GitHub as a public notebook: what repos are, how to read a README, why it matters for Phase 2. Mental models for AI: context window, model vs harness, capabilities vs hype. | Create your GitHub account. Star 5 repos. Read one README fully. Add one mental model to your knowledge base in your own words. |
| Fri | Map your personal AI landscape: what tools are relevant to your work? Where are the gaps? What do you actually want to be able to do in 7 weeks? | Draw your AI tool map (ask Claude to help format it). Write your 小红书 post #1: "I built my AI learning system in one week. Here's the setup." Ship it. |

### Phase 1 Outputs
- Curated X list (10–15 people)
- 2 newsletters subscribed
- Personal AI learning log
- GitHub account + 5 starred repos
- 小红书 post #1

## Phase 2 — Vibe Coding (Weeks 2–3)

> Claude Code as your co-pilot. Your job is taste and direction. Build your portfolio site and open source skill repo.

### Week 2 — Claude Code basics

| Day | Learn | Do / Make |
|-----|-------|-----------|
| Mon | What Claude Code is. Install it. Terminal basics you actually need: `cd`, `ls` — nothing more. Vibe coding mindset: describe outcomes, not instructions. | Install Claude Code. Ask it to explain a folder. Then build a simple HTML page about something you love — describe it like a design brief. |
| Tue | How to give Claude Code good direction: "feel like a luxury brand site" beats "use serif font." Iterate in rounds, like a design review. | Build your one-page portfolio. Brief it as you'd brief a junior designer. Do 3 rounds of feedback and revision. |
| Wed | Git basics: commit, push. Your work becomes permanent and shareable. Writing a one-line README. | Push your portfolio to GitHub. Your first public repo. Write the README. |
| Thu | Reading code you didn't write: asking Claude to explain, modify, fix. You don't need to understand every line — just enough to direct it. | Take a repo you starred in Phase 1. Ask Claude Code to explain it, then ask it to change one thing. |
| Fri | What else can you build this way? Survey: landing pages, tools, prompt playgrounds, generators. | 小红书 post #2: "I built my first website with zero coding. Here's exactly how I described it to AI." |

### Week 3 — Build & publish your open source skill

| Day | Learn | Do / Make |
|-----|-------|-----------|
| Mon | What makes a valuable open source contribution. Your angle: "AI prompt library for brand designers" — only you can write this authentically. | Scope your skill. What 10–15 prompt templates would have saved you time this past year? |
| Tue | Writing a great README: structure, tone, examples. Markdown basics: headers, bullets, code blocks. | Draft your README with Claude's help. Then: "make this sound like a designer wrote it, not an engineer." |
| Wed | Structuring skill files: one file per use case, clear naming, real before/after examples. | Write the core content — your actual prompt templates. Format: task / prompt / example output / tips. |
| Thu | Open source basics: MIT license, issues, inviting contributions. | Add LICENSE file. Final README polish. Make the repo public. |
| Fri | Launch day. | Post on 小红书 + X: "I just open sourced my AI prompt library for designers." Link the repo. This is your stake in the ground. |

### Phase 2 Outputs
- Portfolio site on GitHub
- Open source skill repo (live)
- 小红书 post #2
- First X post with repo link

## Phase 3 — Create (Weeks 4–5)

> Apply everything to your actual craft. Real work, not exercises.

### Week 4 — AI for brand design

| Day | Learn | Do / Make |
|-----|-------|-----------|
| Mon | Lovart deep dive: image gen, brand assets, style consistency. What it does well, where it falls short. | Recreate a real brand brief you've done before — entirely with Lovart. Compare to your original. |
| Tue | Prompt patterns for visual design: style transfer, reference images, negative prompts, aspect ratios. | Build your reusable brand prompt template: `[style] + [subject] + [mood] + [format] + [avoid]`. Add it to your GitHub skill repo. |
| Wed | AI for copywriting: brand voice, taglines, naming. Using Claude as a creative partner without losing your own voice. | Brief Claude on a fictional brand. Get 10 name options + 3 taglines. Edit favorites. Note what you changed and why. |
| Thu | Social asset workflow: one concept → multiple formats. AI for adaptation, not just generation. | Take one Lovart output. Brief Claude on adapting to 3 formats (1:1, 9:16, 16:9) with copy variants for each. |
| Fri | Honest assessment: where does AI speed up your design process vs where does it get in the way? | 小红书 post #3: "I used AI for a full brand project. Honest breakdown — what worked, what didn't." |

### Week 5 — AI for video & creative content

| Day | Learn | Do / Make |
|-----|-------|-----------|
| Mon | AI video landscape: Lovart video, Kling, Runway. Motion prompting vs image-to-video vs text-to-video. | Generate your first AI video clip in Lovart. Try the same prompt with different motion directions. |
| Tue | Scripting with AI: using Claude to write short film concepts, shot lists, storyboards in your voice. | Brief Claude on a 60-second creative film idea. Get a script + shot list. Mark what you'd actually keep. |
| Wed | AI + video editing: transcription, auto-captions, repurposing long content into short clips. | Take a video you've made before. Use AI to generate captions + a 小红书 description from the transcript. |
| Thu | End-to-end content loop: idea → script → visuals → captions → post. | Run one piece of content through the full loop. Document each step and how long it took. |
| Fri | Your creative workflow is now an asset. Document it. | Add your content workflow as a new file in your GitHub skill repo. Post your first AI-assisted short video on 小红书. |

### Phase 3 Outputs
- Reusable brand prompt template
- AI brand mini case study
- First AI video clip
- Documented content loop
- GitHub skill repo updated
- 小红书 posts #3 + #4

## Phase 4 — Ship & Share (Weeks 6–7)

> Tie everything together. Become the AI-literate designer others learn from.

### Week 6 — AI workflows & automation

| Day | Learn | Do / Make |
|-----|-------|-----------|
| Mon | AI workflow tools: n8n, Make, Zapier. The difference between a workflow and an agent — you've built things now, so this clicks. | Map one repetitive task from your actual work. Design the AI workflow for it on paper first. |
| Tue | Connecting tools without code: webhooks and APIs as concepts. How data moves between apps. | Build one automation: e.g. new brief saved → Claude drafts a response outline → saves back to your notes. |
| Wed | Revisit [learn-claude-code](https://github.com/shareAI-lab/learn-claude-code) s01–s03 with fresh eyes. After building things yourself, loop and harness will land differently. | Read those docs. Add to your learning log: "now I understand X because I experienced Y." |
| Thu | Staying current without burning out: your personal AI radar. What to watch, what to ignore, when to act. | Write your personal AI tool stack — the 5–8 tools now part of your actual workflow. Be honest about what you dropped. |
| Fri | Your workflow vs what educators are teaching — where do you agree, disagree, see a gap? | 小红书 post #5: "My personal AI workflow as a designer — what I actually use (and what I dropped)." |

### Week 7 — Capstone + content system

| Day | Learn | Do / Make |
|-----|-------|-----------|
| Mon | Building in public without feeling like a fraud. You don't need to be an expert — one step ahead and honest is enough. | Write your anchor post: who you are, why you started, what you've built in 7 weeks. Your origin story. |
| Tue | 小红书 content strategy: series format, consistent hooks, what works for AI + design content. | Plan 4 weeks of future posts from what you've built. Series idea: "AI tool of the week, tested by a real designer." |
| Wed | Capstone day 1: scope a project using everything — prompting, vibe coding, brand design, video, workflow. | Suggested: AI-generated brand identity for a fictional client, fully documented. Or pitch your own. Scope it today. |
| Thu | Capstone day 2: build and document as you go. Capture decisions, surprises, failures. | Execute. Screenshots, notes, honest commentary. This becomes your richest 小红书 series. |
| Fri | What's next — going deeper. Ideas: AI agents, building client-facing tools, fine-tuning. | Final GitHub skill repo update. Post capstone on 小红书. Reflect: what do you want to learn next? |

### Phase 4 Outputs
- One working automation
- Personal AI tool stack
- Capstone project
- Origin post + 4-week content plan
- GitHub skill repo — final version
- 小红书 posts #5 + #6
